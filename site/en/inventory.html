Find tools locally, then import the list here
  1. Open another terminal in a new, empty working folder.

    You need Node.js 20 or newer. Run the npx command outside the AgentGate source checkout to avoid resolving the same-named local package. Keep your current web server running.

  2. Run local discovery.
    npx --yes --ignore-scripts @zhiliangtech/agentgate@0.6.0 discover --format inventory --out agentgate-tools.json

    This checks supported home and current-directory settings, including Codex MCP settings. It does not start configured tools or export environment values, headers, or complete command arguments. npx may use the network to obtain AgentGate; discover itself does not. The file is written to your current folder and the terminal prints its absolute location. Existing files will not be overwritten.

    For project-specific settings elsewhere, add --roots "/absolute/path/to/project" to the command. Only supported configuration locations are checked; this is not a recursive scan of your computer.

  3. Choose the exported file, then compare it.

    Import agentgate-tools.json below, then choose “Compare inventory”. Do not import raw application settings: they may contain credentials. The list describes discovered configuration, not proof that a tool is running.

No tools found? An empty list only means no exportable configuration was found in the checked locations, not that your computer has no MCP tools. Try the demo without installing anything else. If the terminal reports unreadable configuration, resolve that warning before treating the export as complete.

A name can match more than one publisher. You will be asked to confirm candidates; the page will not guess.

Index versions are reference values only. Confirm your actual version from your own configuration or installation records.

JSON format
[
  { "name": "@scope/package",
    "version": "1.2.3" }
]

This is a demonstration inventory, not your actual installation. The exported report will also be marked as a demonstration. Reset or import a file before switching to your own list.
